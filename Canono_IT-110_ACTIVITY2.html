HTML is the standard markup language for documents designed to be displayed in a web browser.

HTML Document Object Model (DOM)

The Document Object Model (DOM) is a programming interface for web documents. It represents the structure of an HTML document as a logical tree of nodes (objects), where elements, attributes, and text are arranged in parent-child and sibling relationships.

DOM Parent-Child Relationships in this Page

Parent Node Child Node(s) Relationship Explanation
<main> <section> The <main> container holds each content section as direct child nodes.
<figure> <img>, <figcaption> The figure wraps both the image asset and its accompanying text caption.
<ul> <li> Unordered list tags act as parents to individual list item nodes.

In the DOM tree, <html> serves as the root parent node, containing <head> and <body> as immediate children[cite: 2]. All other HTML elements nest under <body> in a hierarchical tree structure.
